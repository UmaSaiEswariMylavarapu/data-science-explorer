Tools of the Trade

Different tools help us collect, process, analyze, visualize, and model data.

🐍

Python

A versatile language used for data analysis, automation, and machine learning.

🗃️

SQL

Used to retrieve and organize information stored in databases.

📗

Excel

Useful for organizing data, calculations, summaries, and charts.

📊

Power BI

Helps create interactive dashboards and business reports.

Real-life example: A college can analyze attendance and examination marks to understand student performance. The analysis may reveal patterns, but it does not automatically prove what caused them.
